# PRD: AI 对话模块

## 背景与目标

底部导航已有「对话」tab，页面目前是占位状态。需要实现完整的 AI 对话界面，让用户能与命理 AI 进行实时交流。

## 需求描述

### 功能
1. **对话界面** — 气泡式聊天 UI，消息按时间排列，支持滚动
2. **智能上下文** — 如果有最近（24h 内）的占卜结果，自动带入对话作为上下文，让 AI 可以结合占卜结果回答
3. **无结果时通用对话** — 没有最近占卜时，AI 以命理师身份回答星座、运势、命理等通用问题
4. **对话历史持久化** — 通过已有的 `contextId` 机制维持多轮对话

### 用户流程
1. 用户点击底部「对话」tab → 进入 `/chat`
2. 页面打开即聚焦输入框，显示欢迎语
3. 输入消息 → 发送 → AI 流式回复（或一次性回复）
4. 对话记录保存在上下文中，返回后可继续

## 技术方案

### 前端 - 新页面
- 重写 `web/src/app/chat/page.tsx`
- 纯客户端组件，消息存在 React state
- 页面加载时调用 `chat.send()` 获取欢迎语（或本地静态欢迎语）
- 每次发送调用 `POST /ai/chat`，携带 `contextId`
- 在发送请求前查询最近占卜记录，如果有则首次请求时附加到系统提示中

### 后端 - 扩展已有接口
- `POST /ai/chat` 已支持 `contextId` 上下文
- 新增一个可选参数 `divinationContext`，前端将最近占卜结果序列化传入
- `chatWithFortuneteller` 增加对占卜上下文的注入

### 数据流
```
用户输入 → chat.send({ message, userId, contextId[, divinationContext] })
         → 后端: 加载历史上下文 + 注入生辰/占卜信息 → AI 回复
         → 保存上下文 → 返回 reply + contextId
```

## UI/UX 变更

- 聊天气泡：用户消息右对齐（品牌色），AI 回复左对齐（浅灰底）
- 输入框固定在底部，支持多行
- 简洁风格，无多余装饰
- 首次进入显示一条 AI 欢迎消息

## 数据模型变更

- `POST /ai/chat` 请求体新增可选字段 `divinationContext?: string`
- 无数据库模型变更

## 验收标准

- [ ] 输入消息能正常获得 AI 回复
- [ ] 多轮对话上下文连贯
- [ ] 带入占卜结果后 AI 能结合占卜回答
- [ ] 无占卜时正常进行通用命理对话
- [ ] 页面样式与现有风格一致
- [ ] 消息气泡显示正常
