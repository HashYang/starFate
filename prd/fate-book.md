# PRD: 命书 (Fate Book)

## 背景与目标

命书是商业化的核心功能，目标是提供**算命先生级别的深度八字命理报告**，让用户愿意为此付费。核心差异化：所有命理数据基于真实算法，AI 仅用于解读，确保"准且有依据"。

## 需求描述

### 功能一：八字排盘（基础）

根据用户出生年月日时，用真实历法算法计算：

- **四柱八字** — 年柱/月柱/日柱/时柱的天干地支
- **五行分布** — 八字中五行的数量统计 + 日主五行
- **五行旺衰** — 基于月令的旺相休囚死判定，标注每个五行的旺/相/休/囚/死状态
- **十神** — 正官/偏官/正印/偏印/正财/偏财/比肩/劫财/食神/伤官
- **纳音** — 年柱纳音
- **用神忌神** — 根据五行旺衰和季节判断
- **神煞** — 天乙贵人、文昌贵人、桃花、华盖、驿马、孤辰（基于日干/日支的传统公式）
- **十二长生** — 各柱地势状态（长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养）
- **藏干** — 各柱地支中的藏干明细

### 功能二：命格总论（核心价值）

- **格局判断** — 基于十神组合的整体格局分析（如"伤官配印"、"杀印相生"等）
- **性格画像** — 基于八字+十神的性格分析（200-300 字）
- **十神组合分析** — 主要十神组合、事业特征、性格体现的深度解读
- **五行生克分析** — 用神忌神关系、最旺/最弱五行及调和建议
- **四维度评价** — 事业/财运/感情/健康，每个维度给出等级、评分和解说

### 功能三：四柱详解（新增）

- **逐柱展开面板** — 年柱/月柱/日柱/时柱，每柱可展开查看详情
- **柱内要素** — 天干地支、五行、十神、藏干、地势（十二长生）
- **AI 柱解读** — 每柱的 AI 深度解读（祖上基业/父母兄弟/自身配偶/子女晚年）
- **藏干分析** — 每柱支藏干的具体影响分析

### 功能四：专项深度分析（新增）

- **事业分析** — 适合行业、职业发展路径、事业黄金期
- **财运分析** — 财运类型、财运周期、理财建议
- **感情分析** — 感情模式、婚恋时机、适合的伴侣类型
- **Tab 切换交互** — 三专项以标签页切换展示

### 功能五：大运流年（最强付费点）

- **大运排盘** — 阳男阴女顺排、阴男阳女逆排，每大运 10 年
- **当前大运解读** — 用户在哪个大运、此大运特点
- **未来三步大运** — 未来 30 年的运势走向
- **当前流年** — 今年的运势分析
- **一生运势曲线** — 总体运势走势描述 + 高峰低谷年龄段
- **关键年份** — 流年/换运等重要年份标记及解读
- **流月运势** — 当前年份 12 个月的逐月评分 + 重点提示（网格视图）

### 功能六：人生建议（增强）

- **综合建议** — 基于八字的人生建议
- **神煞指引** — 天乙贵人（如何借助贵人运）、文昌贵人（学业/事业方向）、桃花（人际/感情）、华盖（自我成长）
- **五行调和** — 五行旺衰的调和建议

### 功能七：命运档案（沉淀价值）

- 所有占卜记录（塔罗/六爻/灵签）自动关联到命书
- 按时间线展示命理历程

## 技术方案

### 依赖
- `lunar-javascript` — 八字/大运/五行、藏干/地势/神煞等核心算法
- AI（DeepSeek）— 仅用于基于计算结果的文本解读

### 架构分层

```
用户生辰 → Calculator（lunar-javascript 计算八字/大运/五行/神煞/地势）
         → 结构化数据（JSON，包含所有计算值 + 神煞 + 旺衰 + 藏干）
         → AI Interpreter（基于结构化数据生成 9 类解读）
         → 命书报告（核心字段 DB 直存 + 扩展内容存 details JSON）
```

### 后端新增
- `backend/src/services/fate-engine.ts` — 八字计算引擎（无 AI，纯算法）
  - 包含神煞算法（天乙贵人、文昌贵人、桃花、华盖、驿马、孤辰）
  - 五行旺衰判定（旺相休囚死，含辰未戌丑四土月特殊处理）
- `backend/src/routes/fate-book.ts` — 命书 API 端点
- `GET /api/v1/fate-book/:userId` — 获取命书完整数据（含 details）
- `POST /api/v1/fate-book/generate` — 生成/刷新命书（传递完整计算数据给 AI）
- `backend/src/services/aiService.ts` — AI 解读服务
  - `FateBookInput` — 包含八字 + 大运 + 神煞 + 五行旺衰 + 四柱详情
  - `FateBookResult` — 包含 9 类新增扩展内容
  - `max_tokens: 4000`，system prompt 覆盖全部 9 类分析

### 前端
- `web/src/app/fate-book/page.tsx` — 命书展示页面，5 章节导航 + 6 大内容板块
  - 八字排盘（增强：神煞卡片组 + 旺衰标签 + 地势表）
  - 命格总论（新增：十神分析 + 五行生克卡片）
  - 四柱详解（新增：3 展开面板逐柱详解）
  - 专项分析（新增：事业/财运/感情 Tab 切换）
  - 大运流年（新增：运势曲线 + 关键年份 + 流月网格）
  - 人生建议（新增：神煞指引卡片组）

### 数据模型变更

```prisma
model FateBook {
  ...
  pattern   String?   // 格局名称
  personality String? // 性格画像
  advice    String?   // 综合建议
  details   String?   // JSON, AI 扩展内容（pillarAnalysis, deepDive, shenshaAnalysis, lifeCurve, keyYears, monthlyFortune 等）
  version   Int       // 版本号，每次刷新递增
}
```

- 核心展示字段（summary, dimensions, dayunInterpretation 等）直接存为模型字段
- 新增扩展内容全部存入 `details` JSON 字段，避免频繁 schema 变更

### AI Prompt 设计

```
系统提示词: FATE_BOOK_SYSTEM_PROMPT (约 200 行)
- 角色设定：子平八字命理大师
- 输出字段：17 个顶级字段（summary, personality, pattern, pillarAnalysis, hiddenStemAnalysis, 
  elementAnalysis, tenGodAnalysis, deepDive, shenshaAnalysis, lifeCurve, keyYears, 
  monthlyFortune, dimensions, dayunInterpretation, liunian, advice）

用户提示词: (约 40 行)
- 用户信息（出生时间/性别/年龄）
- 四柱八字 + 五行分布 + 十神 + 用神忌神
- 四柱详情（含藏干、地势）
- 神煞
- 五行旺衰（旺相休囚死）
- 大运排盘 + 当前大运 + 流年
```

## 价值定位（为什么用户愿意付费）

| 对比项 | 免费运势 | 命书（付费） |
|--------|---------|-------------|
| 八字 | 无 | 真实算法排盘，精确到时辰 |
| 神煞 | 无 | 天乙/文昌/桃花/华盖/驿马/孤辰 |
| 性格分析 | 星座式泛泛而谈 | 基于十神 + 五行生克的精准画像 |
| 专项分析 | 无 | 事业/财运/感情深度解读 |
| 大运 | 无 | 10 年一大运，未来 30 年趋势 + 一生曲线 |
| 流月 | 无 | 12 个月逐月评分 |
| 占卜关联 | 无 | 所有占卜自动沉淀 |
| 内容深度 | 每日一句 | 完整 6 大板块报告 + 可永久查看 |

## 收费模式建议

- 基础命书（八字排盘 + 命格总论 + 四柱详解）— 付费
- 完整命书（含专项分析 + 大运流年 + 流月）— 更高价位
- 按月更新流月运势 — 订阅制

## 验收标准

- [ ] 八字排盘与知名命理网站（如元亨利贞）结果一致
- [ ] 大运排盘正确（阳男阴女顺行规则）
- [ ] 神煞数据正确（与已知传统规则对照）
- [ ] AI 解读基于真实计算数据，不凭空捏造
- [ ] 前端 5 章导航 + 6 大板块正常渲染
- [ ] 四柱详解展开/折叠交互正常
- [ ] 专项分析 Tab 切换正常
- [ ] 流月运势 12 个月网格完整显示
- [ ] GET 缓存返回完整数据（含 details）
- [ ] 页面加载性能良好
